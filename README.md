README — SmartBudget Manager
A quick-start guide for new users
What does it do?
SmartBudget Manager is an Excel workbook that helps you record income and expenses, compare spending with monthly category budgets, and review your overall monthly balance on a Dashboard.
What do you need?
•	The SmartBudget_Manager.xlsx file.
•	Microsoft Excel 2016, 2019, 2021, Microsoft 365, or a compatible spreadsheet application.
•	Basic knowledge of entering data into spreadsheet cells.
Workbook contents
•	Dashboard — totals, monthly balance, budget status, category summary, and chart area.
•	Transactions — one row per income or expense transaction.
•	Categories — predefined categories and their monthly budget amounts.
Get started in 5 steps
1.	Open SmartBudget_Manager.xlsx and enable editing if prompted.
2.	Select the Transactions worksheet.
3.	On a new row, enter the date, description, type, category (for expenses), and the amount in the correct Income or Expense column.
4.	Do not overwrite formula-driven Month cells. Use the predefined category names where possible.
5.	Open Dashboard to check the totals, category summary, and budget status; save your copy.
Important notes
The sample workbook contains example transactions. Replace or remove sample data carefully before using it for your own budget. Keep a backup copy and do not share the file if it contains private financial information. If the budget status indicates OVER BUDGET, review category spending and budget limits.
